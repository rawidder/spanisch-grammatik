# Spanisch-Grammatik

Lern-App für die spanische Grammatik (für Deutschsprachige): Merkblätter, Übungen mit Sofort-Korrektur und Lernkarten zu 30 Kapiteln. Eine einzige HTML-Datei, optimiert fürs iPhone.

**App öffnen:** https://rawidder.github.io/spanisch-grammatik/

Auf dem iPhone in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
